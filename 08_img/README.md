# 教科書用図版格納ディレクトリ

クラウドネイティブ教科書で使用する図版ファイルを格納するディレクトリです。  
本ディレクトリには、本文中で利用する SVG 図版および関連ファイルを配置します。

---

## 目的

本書は単なる手順書ではなく、「なぜその技術や構造が必要になるのか」  
を理解することを目的としています。

図版についても同様に、技術要素の説明ではなく、  
構造理解を補助することを目的として作成しています。

---

## 命名規則

図番号に対応した名称を使用します。

例

* figure_P-1.svg
* figure_1-1.svg
* figure_1-2.svg
* figure_3-1.svg
* figure_3-3.svg
* figure_4-1.svg
* figure_4-2.svg
* figure_4-2.1.svg

修正版を保持する場合は末尾に版数を付与します。

例

* figure_3-1_v2.svg
* figure_4-2_v3.svg

最終版は版数を除去して配置します。

---

## 図番号体系

図番号は掲載箇所に対応します。

* P-x : 序章
* 1-x : 第1部
* 2-x : 第2部
* 3-x : 第3部
* 4-x : 第4部
* 5-x : 第5部

同一図の補足図は小数点形式を使用します。

例

* 図4-2
* 図4-2.1
* 図4-2.2

## 編集方針

図版は以下の優先順位でレビューを行う。

1. 本文との整合性
2. 読者理解
3. PDF可読性
4. デザイン改善

構造変更よりも、「読者が誤解しないこと」を優先する。

また、図単体ではなく本文とセットで意味が成立することを前提とする。
